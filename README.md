# Computer Science Club App

This App is for tracking the meeting that the Computer Science club hosts.

## Screens

- **Home** - Add New meeting, allows user to go to all list and the about page
- **List** - Shows all the meeting in a scrollable list, and allows u to clear all or one.
- **About** - User can read what the app is about.

## Input Rules

Has to be longer then 3 characters
Cant be longer then 40 characters
Cant be only numbers
Capitals and Lower case doesn't matter

## How To Run

1. Clone this repo
2. Open the cloned folder in Android Studio
3. Wait for Gradle sync, then run

## Known Limitations

Added or removed meetings in the app won't be saved.
